# EBOL WASHPOINT v1

Aplikasi kasir Android untuk EBOL WASHPOINT.

## Fitur
- Dashboard omzet, pengeluaran, kendaraan, dan laba bersih
- Kasir kendaraan dan layanan tambahan
- Riwayat transaksi
- Input pengeluaran
- Laporan bulanan
- Penyimpanan lokal di perangkat
- GitHub Actions untuk build APK

## Rumus
Laba Bersih = Omzet - Total Pengeluaran

Tidak ada pembagian 60%/40%.

## Build APK di GitHub
1. Upload seluruh isi proyek ke repository GitHub.
2. Pastikan branch utama bernama `main`.
3. Buka tab **Actions**.
4. Pilih **Build EBOL WASHPOINT APK**.
5. Klik **Run workflow**.
6. Setelah selesai, buka hasil workflow dan download artifact **EBOL-Washpoint-APK**.
